# جدول الحكم

جدول تمارين ومدرب لياقة للحكم المساعد: خطة أسبوعية، صور ورسومات للتمارين، مؤقت راحة، فحص جاهزية، حمل تدريب، تقييم مباريات، وتقرير أسبوعي من المدرب.

## التشغيل على ريندر

1. ارفع هذا المجلد كامل لمستودع جديد على قت هب.
2. في ريندر: جديد ← خدمة ويب ← اختر المستودع. الإعدادات موجودة في ملف الإعداد، وأمر التشغيل هو تشغيل ملف الخادم.
3. أضف متغيرين في إعدادات البيئة:
   - مفتاح واجهة Claude البرمجية (لازم عشان المدرب يشتغل).
   - رمز دخول تختاره أنت (يحمي المدرب من أي أحد يعرف الرابط).
4. افتح الرابط من سفاري، ثم مشاركة ← إضافة إلى الشاشة الرئيسية. بتطلع أيقونة راية الحكم المساعد.

## نقل بياناتك

من صفحة التقدم ← نسخة احتياطية ← استيراد نسخة، واختر ملف النسخة الاحتياطية.
